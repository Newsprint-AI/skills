# Newsprint skills

Free [Agent Skills](https://agentskills.io/specification) from [Newsprint](https://www.newsprint.com), under the MIT license.

| Skill | What it does |
|---|---|
| [write-release](skills/write-release/) | Interviews you for the facts, then writes an AP-style press release that reporters can use and AI answer engines can quote. It never invents facts, figures, or quotes. [About this skill](https://www.newsprint.com/skills/write-release/) |

## Install

With the [skills CLI](https://skills.sh):

```
npx skills add Newsprint-AI/skills --skill write-release
```

Or paste this into your agent:

> Install the write-release skill by running `npx skills add Newsprint-AI/skills --skill write-release`. If you can't run commands, read https://github.com/Newsprint-AI/skills/blob/main/skills/write-release/SKILL.md and the files it links to, and follow it for the rest of this conversation.
